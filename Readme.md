# Applied Data Science Portfolio

A collection of end-to-end projects demonstrating applied data science, causal inference, econometrics, optimization, deep learning, and generative AI — built to reflect the full lifecycle of a production data scientist: simulate or source data, model it rigorously, quantify uncertainty, optimize decisions, and ship something usable.

## Projects

### 1. Retail Pricing & Capacity Optimization Engine
`01-retail-pricing-optimization/`

An end-to-end decision science platform simulating an omnichannel retailer (Nova Retail). Recovers price elasticities from simulated transactional data using classical econometrics and Bayesian methods, then optimizes prices under business constraints (margin, inventory, price bounds) via mathematical optimization, delivered through an interactive dashboard.

**Skills:** Data Simulation, Applied Econometrics, Bayesian Inference, Mathematical Optimization, Streamlit

**Status:** In progress

---

### 2. Customer Lifetime Value Prediction Using Deep Learning
`02-customer-lifetime-value/`

A production-quality ML pipeline predicting future customer lifetime value from structured behavioral data. Compares baseline regression and gradient boosting against deep neural networks, with SHAP-based explainability and an inference pipeline tracked in MLflow.

**Skills:** Feature Engineering, Supervised Learning, Deep Learning (TensorFlow/Keras), Explainable AI, Model Deployment

**Status:** Planned

---

### 3. Enterprise Retrieval-Augmented Generation (RAG) Knowledge Assistant
`03-rag-knowledge-assistant/`

An enterprise-grade GenAI application answering natural language questions over a corpus of business documents with citation-backed responses, built as a full retrieval system rather than a thin LLM wrapper — ingestion, chunking, embeddings, vector search, reranking, and evaluation.

**Skills:** Retrieval-Augmented Generation, Vector Databases (FAISS/Chroma), LLM Engineering, Prompt Engineering, Semantic Search

**Status:** Planned
